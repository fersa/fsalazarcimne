## Co-inventor of two patents

- “[Concrete precast unit with drainage and aeration system for protection against water currents](https://consultas2.oepm.es/InvenesWeb/detalle?referencia=P201630941)”, N. ES2595852.
- “[Recoverable fuse gate of polygonal spillway with opening and closing system of a section of water passage in hydraulic structures](https://consultas2.oepm.es/InvenesWeb/detalle?referencia=P202130736)”, N. ES2894904.

## Open-source software applications

- **SOLDIER.** SOLution for Data Interpretation and Evaluation with Regression-trees. Main developer. Software for training and applying machine learning predictive models for dam safety assessment. Described in a [scientific article](https://www.sciencedirect.com/science/article/pii/S2352711023002947). [Github repository](https://github.com/cimnemadrid/SOLDIER).
- **ACRÓPOLIS.** Graphical User Interface for Classification of Risk for Off-Stream Reservoirs Using Machine Learning. Co-developer. A stand-alone graphical user interface (GUI) for hazard classification of off-stream reservoirs with machine learning models. Described in a [scientific article](https://www.sciencedirect.com/science/article/pii/S2352711024000281#sec0002). [Github repository](https://github.com/nathaliasilvac/ACROPOLIS).
